# Exact saved Resume Flag in the pinned interrupt path

V1 OFF retained one real SIGVTALRM context before stopping at gate two. Its
sixteen saved GPRs, arithmetic progress, final resume state and non-RF flags
matched. Saved RFLAGS was 0x10206; the first oracle incorrectly expected 0x206.
The failed capture, offline inspection, source freeze and owned cleanup are
bound in artifacts/m3b-natural-signal-off-failure-01/decision.json. No V1 ON
capture was attempted.

The actual pinned source target/i386/tcg/seg_helper.c has do_interrupt64 choose
set_rf=exception_is_fault(intno) for every non-software interrupt, including
ordinary hardware vectors. exception_is_fault returns one for these vectors;
the saved stack flags include RF_MASK. translate.c clears RF on the subsequent
ordinary instruction path. These exact source identities are frozen as V2
dependencies. This explains the observed baseline path; it is not an external
validation of hardware RF semantics.

V2 requires exactly expected arithmetic/control flags OR 0x10000 at the saved
signal boundary. It does not mask RF or accept both values. Corruption tests
reject absent RF and any changed TF, IF or carry bit. Final resumed RFLAGS must
still equal 0x246. All sixteen GPR checks, code bytes, fixed loop counts, timer
type/deadline, single delivery, native counters, cap and compiled-owner checks
are unchanged. The guest is rebuilt because its C validation changes too.

Retain V1 unchanged. Execute one new V2 OFF and one V2 ON after the actual SDK
build, host checks, source freeze and checkpoint. No timing or promotion claim.
