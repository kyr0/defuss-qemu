# Independent fused-pressure evidence review

This draft passed12 synthetic tests and six AST checks in
`artifacts/m3b-fused-pressure-review-tests-01`; it has not replayed a pressure
capture. Those seven tested sources are retained under
`artifacts/m3b-fused-pressure-review-before-controller-pin-01`. The subsequent
controller identity hardening adds a thirteenth test, still unexecuted at
authoring. Actual pressure source01 and independent source-review01 are pinned;
this reviewer's own source freeze and independent review remain required.

The reviewer reads the saved raw serial, progress, chunk ledger,96/128/256/2400
native banks and stopped JIT response. It reconstructs the bounded guest work
and protocol independently from the JavaScript harness, then proves that the
sentinel was compiled before the first6000 FIFO positions, never ran during
churn, belonged to the actual first6000 retirement, and re-entered compiled code
under the same native descriptor/generation/page/context after natural capacity
release. It checks the hard12000 charged cap and live/pending accounting bounds.
An RF owner cannot substitute for the required normal fused compiled re-entry.

All eight segment caches retain ABI2 canonical access flags and raw evidence.
There is no watch reset after the layout gate. A global TB flush after warmup,
faulted census, typed injection, owner change, incomplete16-retry horizon or
wrong selected tier rejects acceptance. The n×step guest assertions are bound
to the exact copied C/assembly, actual ELF bytes and source-derived check totals.
Entry counts are not called retired bodies. Natural charge release is not
assigned to a particular GC callback or an exact global installation count.

The three files `baseline.py`, `semantics.py` and `trace.py` are unchanged
copies from the frozen independent baseline reviewer source02. Its exact
manifest/review and copy identities are rechecked. They provide independent
Python native-bank decoding, ABI2 tuple semantics, source/build binding and
raw chunk/host-condition primitives. New `pressure.py` supplies the lifetime
state machine; `review.py` separately checks the pressure image, SDK commands,
literal graph, raw protocol, served identities, source closure, actual process
records and browser cleanup. No JavaScript oracle is executed by this tool.
The copied execution controller must match both the execution request and the
exact controller already frozen in the pressure source dependency map.

The pressure source freeze and review, actual image, accepted baseline inventory,
runtime7, controller and raw input identities are all required. The caller must
also provide this reviewer's frozen source manifest and independent source
review. No report's `passed` field alone grants acceptance. Full OFF and ON
captures must be complete, replayed offline, cleaned up and serially ordered.
The reviewer freeze must retain the before-controller manifest, all seven
archived files and their passed tests01 report as dependencies.
