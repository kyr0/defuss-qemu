# V2 closes the explicit browser module list

V1 OFF failed during module import, before native startup or any guest serial
bytes. Its one header row, frozen source, failed report and cleanup remain in
artifacts/m3b-signal-alias-off-launch-failure-01/decision.json. V1 ON was not run.

The guest contract imports the accepted natural-signal-v2 arithmetic helpers.
That dependency was bound by the source freeze but missing from the browser
serve list. V2 serves those exact bytes, centralizes the declared browser module
list, and checks every literal transitive module import against it during
preflight and again before browser launch. A negative host test removes the
formerly missing module and requires refusal. The inspector checks every
listed module was actually served with its bound hash.

Guest C/assembly, timer, fixed work, alias patch, integer state and native
acceptance are unchanged. The path/protocol version and build receipt change;
a fresh SDK build will compare the actual guest ELF/rootfs identities to V1.
Exactly one fresh V2 OFF and one ON are declared. Failure or zero exposure is
retained without automatic retries. No timing or promotion claim.
