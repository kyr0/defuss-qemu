Audio routing
SB16 is enabled by default. Playback starts with Start PC; no microphone permission is needed. Display and diagnostics Enable Helper profiler before boot for named compiled-helper timings. Leave profiling off for speed comparisons.
Idle
MMU diagnostics use nominal 1/256 pseudo-random sampling by default. Raw sample counts and selected bytes are not full totals; the JSON records the actual sampling mode. Detailed TCG profiling remains optional. Recording can start before boot. Download is available at any time, including after a failed start. The trace records device counters, display/input timings and, with TCG sampling enabled, interpreter opcodes/pairs and JIT compilation time. The preboot helper profiler adds compiled-helper counts and sampled timings. TCG opcodes are emulator operations, not x86 assembly. Audio traces include frame counts, queue depths and peak levels. They omit audio samples, device names and typed keys.
