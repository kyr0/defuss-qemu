# Owning vCPU worker service suspension

One fixed diagnostic pressure sequence per arm, with the newly bound native
observer and derived JS. The original ABI2 runtime and every prior capture
remain unchanged. This is not a timing experiment.

The 12,000 generated loops, 100,000 iterations per invocation, 64-loop batches,
and 256 MiB diagnostic translation buffer remain fixed. Before warming the
static fused sentinel, execute batches until normal instance installations
reach at least 7,000 (and remain below 11,000, with no retirement). Warm the
sentinel eight times, then continue the same generated loops until the first
ordinary retirement of 6,000 instances. Perform exactly 16 sentinel revisits,
with the existing one-second guest sleeps between them. A maximum of 12,000
generated nodes and a 30-minute capture deadline apply. No forced collection,
countdown reset, capacity change, invalidation action or automatic repeat.

The host fsyncs each raw stream prefix and stopped native bank before decoding
or acknowledging a guest gate. OFF must preserve arithmetic and have no
observer candidates. ON must additionally provide at least one completed
compiled episode for the watched sentinel's exact code/owner/generation,
with native worker identity, all four real Asyncify transitions, zero debt,
one B/service payment, and identical captured before/after native state.
Every captured episode must validate. At most four episodes are retained;
additional candidate attempts are counted as overflow without being sampled.
No qualifying episode yields an incomplete outcome, never a pass.

The generated function returns before the original service helper can sleep.
This observes a suspended native dispatcher/service continuation on the owning
worker, not an active generated-WASM frame. The captured raw GPR, lazy flags,
control and segment fields are not complete XSTATE. Guest XSTATE preservation
has separate accepted evidence. Suspended-owner invalidation, natural interrupt
semantics, alias SMC, resource and performance gates remain separate.

Host model tests, capture, and same-code offline replay are authored by the
same agent. A separate-language reconstruction is required before accepting
this milestone; no external independent source audit is implied.
