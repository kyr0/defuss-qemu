# M3b context accounting v2

This isolated revision requires native census ABI2 and the v2 host runner. It preserves all frozen v1 sources and their evidence. Source and synthetic corruption fixtures are prepared; v2 host tests, runtime build and real captures remain unexecuted at authoring. No live v2 outcome is claimed.

The actual v1 OFF capture failed at gate5/add64 warm with sticky census fault24. Its first bad tuple differed only in redundant CS/SS descriptor-limit encoding bits. This finding does not forgive that bank: a sticky first-fault record cannot establish every later context. The v1 capture remains failed and the change requires a new native runtime and fresh captures.

ABI2 keeps the2400-word bank and112-word tuple but stores canonical segment access flags at the existing locations, exact raw segment flags at tuple90..97 (ES/CS/SS/DS/FS/GS/LDT/TR), and zero reserved98..111. Each canonical field must equal its raw copy masked with `0x00f0ff00`: G/B/L/AVL/P/DPL/S/TYPE including accessed/type bits. Excluded descriptor bits redundantly encode parts of the base or limit; selector, full decoded base and decoded limit remain separately exact. Native continuity and host owner/context equality skip only raw-copy words90..97. Every native sticky fault remains fatal.

The CPU-dump parser still validates and retains each complete numeric row and its exact descriptor display. Semantic trace equality masks only those segment flags and compares every separate selector/base/limit/control/debug value. Raw display strings are retained as diagnostics, not compared as semantic identity. A later printed raw descriptor encoding need not equal the first native raw copy, but its canonical access flags and decoded cache must match. V2 does not change RF certificates, attempted-entry accounting, guest work, or acceptance margins.

The closed forensic-v2 gate3 trace independently contains64 completed RF A-to-B preludes,9 RF A-to-side preludes and10 exact RF A entry refusals. The64 positive continuations match the gap between486 fused B boundary attempts and550 guest-checked bodies. Seven RF B records are also present: three generic entry refusals and four later B-to-A transitions. They belong to existing continuations, so they add no term. These are observations about this diagnostic capture; the original unlogged ON01 cause remains unproven and both captures remain failed.

The proposed logical expression is `F + R + D = (F - P) + P + R + D`: F is the existing fused boundary-attempt count; P is its requested-exit subset; R counts exact completed RF A-to-B preludes; D is the guest's explicit initial direct-B call count. The extra service count must remain exactly F. Ordinary B selected entries are attempted entries, not retired bodies, and never enter this expression. All original per-call state checks, guest digest/check count, bounded work and negative-shape checks remain required.

`parseContextTrace` imports the new runner's capacity-only parser revision (512MiB total,64MiB per stopped window) and separately requires every printed control, segment and debug field. The RF parser/classifier semantics remain unchanged. `classifyContextWindow` checks the full recorded context, exact full cflags including cluster255/COUNT0, all visible PCs/owner pointers, RF A certificates and bounded RF B continuation chains. Its two B-body decoders match the retained register-only fixture bytes; they are offline evidence checks, never runtime admission rules. This standalone diagnostic function rejects an RF B origin lacking a certified A continuation.

`validateContextWindow` consumes `{parsed, layout, window:{start,end}, gate, before, after, ownerBaseline}`. `before` is the configured/reset stopped row, `after` is the exact stopped gate row, and `ownerBaseline` is the same program's warm gate row. These contain raw96/128/256-word banks, stopped status, captured errors, native status and pool observation. It checks the unchanged reference gate, native validity/monotonicity, exact epochs/ranges, unique warm fused emission, stable generation, no measured fusion retry/emission or invalidation/retirement, and the proposed equation. It always returns `acceptance:false` and `blocked-owner-continuity`. No caller-supplied boolean can change that.

The original trace has60 more native normal fused attempts than logged normal outer A entries. Recorded CR3/context constancy and aggregate counter equality cannot bind those unlogged internal entries to a physical code page and owner. The separate new native census addresses that specific gap; original-runtime captures cannot supply it. `census-browser.mjs` contains only browser-safe configure/raw-read/watch transport. Raw banks must be durably recorded before `census-reader.mjs` performs host semantic decoding. Exact binding variant `m3b-context-census-v2`, extensions `context-entry-census-v2` and `generation-specific-injection-v1`, and ABI2/2400words/4slots are mandatory.

`validateCensusContextWindow` is the explicit new-runtime per-window entry point. Its input is the prior structure plus `binding`; before/after/warm rows additionally contain `censusRaw` and `censusNativeStatus`. The census is enabled in both M3b modes; only positive ON windows require fusion. All four census reset epochs match the existing watch epochs, with only slot0 active at exact A. Actual selected-tier entries are partitioned by native context and tier; every RF attempt must match a complete raw RF-A frame including refusals, and every normal attempt must have the stable fused owner. Native physical-page/generation/context tuples remain stable since warm, every printed A code pointer/context matches its tuple, old M3b tiers match the census, and all compiled A census sites equal existing M3a selected A. Unexpected categories, faults, tuple changes, unclassified frames or contradictory evidence fail. OFF and rejected-shape ordinary-normal paths retain their original checks.

Only after all those native proofs pass does a private, unexported proof allow an RF-B retry/body group without an RF-A certificate to be described as an unassigned member of the existing D/P route set. This is a source-CFG argument, not an inference from the count bound: the unchanged guest enters B directly only for D; the unchanged private requested exit produces B only for P; ordinary RF A contributes only the exact R certificates; exhaustive census excludes ordinary-normal/other A. The helper-free, immutable B body has no instruction fault or interior branch, and its only closing edge is A. Exact same-state generic refusals must lead to a checked B-body-to-A transition. Such groups add no term, are not individually attributed to D or P, and must additionally number no more than D+P.

Two ambiguities remain explicit fail-closed cases. If the immediately preceding logged normal B might belong to an earlier completed invocation, this implementation still requires it to be the exact refused origin; it rejects a missing refusal or state mismatch. Also, the unchanged RF-A classifier rejects any RF-A exit whose required adjacent normal B/side frame is absent or context-mismatched, including a possible internally chained refusal seam. No warm-up ambiguity is converted into a measured-window certificate. Any future extension needs a separate source proof and review before a new capture.

The new function returns `windowAccepted:true` only for that one census-complete positive window, while `acceptance:false` still prevents interpreting it as whole-capture acceptance. The old `validateContextWindow` remains a blocked diagnostic. New tests include explicitly non-evidence hybrid fixtures: historical raw frames with fabricated census banks exercise integration and corruption rejection. They do not assert that any census runtime produced those banks.

Full capture closure, queue hashes, raw serial/progress, exact source/runtime/SDK/image provenance, and all45 original guest rows require a separate independent capture replay. This pure module cannot certify those external artifacts. Recovery windows that deliberately change a generation need a separate scoped contract; this stable-owner draft cannot be reused by relaxing its guards.
