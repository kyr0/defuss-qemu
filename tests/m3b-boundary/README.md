# M3b native boundary fixture draft

All ten boundary host tests passed in the root-run25-test suite at `artifacts/m3b-safe-gap-host-tests-03/fixtures.log`; Python AST and all staged JavaScript syntax checks also passed in its `report.json`. These are synthetic host contract/provenance/replay checks, not selected guest evidence. Image construction and real guest execution remain unrun. This separate fixture preserves the earlier45-gate workload and its evidence. It requires the new256-word boundary bank while retaining the existing128-word M3b watch ABI. Its future launch must use `-global apic.vapic=off`, the exact one-CPU/private512MiB profile and a newly reviewed safe device graph. The observed earlier graph containing kvmvapic is not eligible.

Two generic register/immediate programs perform32-bit ADD/XOR/SUB or64-bit XOR/ADD/SUB, with one conditional A side exit and closing B-to-A JMP. Each program warms2048 A calls and2048 direct-B calls with count4. Four subsequent single A calls use fixed counts3 (budget-return observation) and5 (private forced-B-request observation), once per program. There are8196 complete calls,11 stopped G/K gates and four INPUT/RESULT pairs. Guest C and independent host BigInt code compute the complete final state/digest. The deterministic stream uses seed0x6c7e9241a5d038bf; input register identities/immediates are fixture data, never admission guards.

Before each probe, the guest prints all16 seeded GPRs, user flags and the prior-side-effect count, then blocks at a before gate. The host must durably record the raw serial/input and stopped raw banks, validate that input against `reference(layout)`, reset exact A/B watches, and arm exactly this one A PC/request/mode only in ON. The next guest operation increments one prior counter and executes one known nonzero-body call. Its final result preserves all16 GPRs/user flags, the prior increment exactly once and defined legacy FP/SSE state. The subsequent after gate must retain the full256-word bank before validation/ACK. No fallback, wrong tier, first-hit early exit, failed/armed bank, missing input, timeout or source drift is replaced or retried automatically.

The native oracle checks all16 before GPRs/flags against the fixed input, exact A entry EIP and the expected POPFQ-materialized CC_OP_EFLAGS representation. Mode1 must return IDX1 at A after exactly one body:32-bit writes zero-extend EAX/ECX;64-bit writes update R10/R9. Mode2 must return REQUESTED at B after A's CMP, with every GPR unchanged. Both check the actual SUBL/SUBQ lazy operation, live CC source/result and independently computed arithmetic flags. The32-bit raw lazy result retains the seeded upper RCX bits: the ordinary x86 emitter computes full target_ulong T0, truncates only architectural register writeback and then stores full T0 into cc_dst; SUBL interprets only its low32 bits. Both probe modes explicitly reject truncating this raw result, even if the third snapshot is altered consistently. The source-derived numeric CC operation values18/19 come from retained `target/i386/cpu.h`; the live operand representation follows `emit.c.inc:gen_SUB/prepare_update2_cc`. If real source lowering differs, retain the failure for review rather than silently changing the oracle. Unused stale CC operands have no architectural expected value but remain captured. Raw EFLAGS, DF, hflags, hflags2, CS/FS/GS bases, CR0/CR4/EFER must remain unchanged.

Each bank must carry one actual compiled fused invocation, exact owner A/B extent/generation/six guest instructions, one before/after/completion callback, service+1/attempt+1 and requested+(mode2), cleared debt, no saturation and Normal after service. The third64-word snapshot must equal the post-call snapshot exactly. Host range counters must independently confirm this exact A owner was compiled, generation agrees and B remains an ordinary owner; the per-call body conservation must include the intentionally resumed ordinary B in forced mode. OFF must execute identical guest work with an idle boundary bank and ordinary compiled exposure; no OFF bank is fabricated for comparison.

`fixture.S` copies the earlier small trampoline under new symbols and contains only the two new programs. `fixture.c` provides deterministic inputs/final-state checks and raw protocol. `contract.mjs` provides the independent stream/native oracle; `reader.mjs` validates the new bank with acquire/stopped reads; `test-contract.mjs` contains five synthetic corruption tests, now passed host evidence. `test-data.mjs` supplies labeled synthetic layouts/banks; `test-replay.mjs` adds three complete-journal/lifecycle corruption tests and `test-build-provenance.mjs` adds two SDK/compiler-input tests. All ten passed in the retained suite03 log. Real ELF/disassembly/layout, copied source and pinned SDK/runtime/graph provenance remain required before a launch adapter is accepted. The draft adapter invokes `tests/m3b-profile/controls.mjs` at exact prelaunch before first cont, retaining its immutable readbacks and durable guard rejections.

A complete bank proves only the observed call and service-return state relationship. Mode2 is a private diagnostic requested-exit selector, not proof of naturally arriving interrupt behavior. Equal state and AsyncifyNormal do not prove the VM actually yielded. Separate emitted-WASM unwind/rewind evidence and eventual natural-pressure VM evidence remain open. Native snapshots omit complete FP/XSAVE/system state; the final legacy FP/SSE check does not cover extended YMM. No performance or promotion conclusion is possible from this fixture.

## Staged build and launch (image build and guest unrun)

`build.py` and `build-provenance.mjs` are isolated derivatives of the earlier fixture tools. They bind copied C/S/predecode bytes, exact static ELF symbols/disassembly/six-instruction owner layouts, actual SDK command/start and later successful wrapper completion, compiler/nm/objdump identities, and the copied input/header used by the host shape probe. The ELF stack symbol supplies the exact stack pointer used by the independent input stream. Source and copied artifacts are rechecked after construction. The original tools/evidence remain unchanged.

`guest.mjs` waits for readonly query-cpus-fast startup completion and records all eleven stopped gates, all three native banks and all four arms through `run.mjs`'s fsynced journal before host validation or ACK. Before typed decoding it copies bounded raw96/128/256 banks, pool/status and, at startup/control readback, graph/object bytes. A decoding failure emits a durable snapshot-failure row before rejection. It invokes the native control helper before the first `cont`; replay requires exact zero-execution initial M3b state and zero M3a counters/fallback/injection state. Build acceptance requires the exact ten source dependencies and pinned base-initramfs identity. `replay.mjs` independently validates its twelve operations and unchanged raw readbacks, exact watch epochs, lifetime counters, all guest inputs/results, one-shot lifecycle, selected owner generation, native state and full body/service conservation. Raw serial must exactly reproduce the fixed layout plus all twenty ordered protocol records, with eleven matching COM1 signals. Failed, incomplete or changed-input runs are retained and never automatically retried; a partial journal cannot pass. Host-fatal termination can still leave a missing raw serial tail, which is an evidence failure.

The runtime identity validator is reused from `tests/m3b-fallthrough/runtime-identity.mjs` without modification. It requires actual reviewed graph/source/build/recheck and all seven runtime artifact identities. Native prelaunch must establish the new safe vAPIC-disabled profile; the old graph with kvmvapic cannot be used. Root must create the real binding only after those artifacts exist; no placeholder is accepted as a successful binding. Explicit Chrome identity, compiler VM Stopped before/after, exact required served modules and final input hashes are retained.
